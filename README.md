# LEX // ARCHIVE

A personal portfolio for selected web development, QA, systems, and creative work.

## Files

```text
lex-archive/
├── index.html
├── style.css
├── app.js
├── README.md
└── assets/
    ├── images/
    └── projects/
```

## Run locally

Open the folder in VS Code and use Live Server on `index.html`.

No framework or build step is required.

## Current features

- Responsive editorial/archive-style layout
- Selected project files
- Project category filters
- Accessible project detail dialog
- Mobile layout
- GitHub and live-project links where available
- Contact section ready for an email address

## Before publishing

Open `app.js` and replace:

```js
const portfolioEmail = "";
```

with your real portfolio email.

Project text and links are stored in the `projects` object near the top of `app.js`.
