### FILE 008 — SmartFlow

**IoT-assisted water-flow anomaly detection and leak-alert decision-support system**  
**Role:** System Analyst  
**Status:** Title approved · In planning

A proposed web and mobile decision-support system for a selected water district in Dasmariñas, Cavite. The concept combines IoT water-flow monitoring and machine-learning anomaly detection to help authorized personnel review possible irregularities and manage field inspections.

**Proposed features**
- IoT water-flow monitoring
- Machine-learning anomaly detection
- Automated alerts for potential anomalies
- Web monitoring dashboard
- Mobile field-inspection management
- Historical reporting and role-based access

**Proposed stack:** React.js, Flutter, Node.js, Express.js, PostgreSQL, Python, Scikit-learn, IoT sensors and microcontroller, JWT

This project is in the planning stage. Alerts are intended to indicate potential anomalies, not confirm a leak or identify its exact location. Physical inspection is still required. The proposed project aligns with SDGs 6, 9, and 11.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/lexyian/LEX-ARCHIVE.git
   ```

2. Open the project folder:

   ```bash
   cd LEX-ARCHIVE
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No package installation or build command is required.
